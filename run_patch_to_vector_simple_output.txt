🎯 核心：16x16 patch 如何变成 384维向量？
==================================================

📊 基础数字：
- 输入：16×16×3 = 768 个像素值
- 输出：384 个特征值
- 转换：卷积神经网络

🔧 核心机制：
1. 创建 384 个卷积核
2. 每个卷积核：16×16×3 = 768 个权重
3. 每个卷积核处理整个patch，输出1个值
4. 384个卷积核 → 384个值 → 384维向量

⚖️  计算公式：
输出[i] = Σ(像素值 × 卷积核[i]的权重) + bias[i]
其中 i = 1, 2, ..., 384

🧠 学到的特征：
- 维度1-3：红绿蓝颜色强度
- 维度4-10：各种边缘模式
- 维度11-50：纹理特征
- 维度51-384：复杂视觉模式

📈 参数数量：
- 每个卷积核：768 个权重
- 总权重：294,912 个
- 加上bias：295,296 个参数

💡 简单类比：
想象384个不同的'专家'看同一个patch：
- 专家1：专门看红色程度
- 专家2：专门看绿色程度
- 专家4：专门看垂直线条
- 专家5：专门看水平线条
- ...
- 专家384：专门看某种复杂模式

每个专家给一个评分，384个评分就是384维向量

🎯 关键理解：
1. 不是简单压缩，而是特征提取
2. 每个维度都有特定的语义含义
3. 通过训练学习到最优的权重
4. 相似的patch产生相似的向量
